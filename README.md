# 시계 배우기 (BabyClockLearn)

아이들이 시계 보는 법을 재미있게 배울 수 있는 한국어 웹 앱이에요.

## 할 수 있는 것

- **바늘 돌려 보기**: 아날로그 시계의 시침·분침·초침을 손가락이나 마우스로 끌어서 시간을 바꿔요. 분침이 12를 지나면 시침도 함께 넘어가요.
- **시간 듣기**: 버튼을 누르면 지금 시각을 한국어로 읽어 줘요. 예를 들어 "세 시 이십오 분"처럼요.
- **12시간 / 24시간 표시**: 원하는 방식으로 바꿔 볼 수 있어요.
- **남은 시간, 지난 시간 계산**: 바늘로 정한 시각까지 얼마나 남았는지, 또는 얼마나 지났는지 알려 줘요.
- **현재 시각으로 돌아가기**: 바늘을 움직인 뒤에도 버튼 하나로 지금 시각으로 돌아와요.

휴대폰 화면과 터치에 맞춰 만들었고, 나중에 안드로이드 앱으로도 낼 계획이에요(Capacitor 사용, 준비 중).

## 실행하기

[Node.js](https://nodejs.org/)가 설치되어 있어야 해요.

```bash
npm install     # 처음 한 번만
npm run dev     # 개발 서버 실행
```

브라우저에서 http://localhost:5000 을 열면 돼요. 포트를 바꾸고 싶으면 `PORT` 환경 변수를 설정하세요.

### 그 밖의 명령어

```bash
npm run build   # 배포용으로 빌드 (결과물은 dist/ 폴더)
npm start       # 빌드한 앱 실행
npm run check   # TypeScript 타입 검사
```

Windows, macOS, Linux 어디서나 똑같이 쓸 수 있어요.

## 음성에 대해

- 브라우저에서는 브라우저에 들어 있는 음성 기능(Web Speech API)을 써요.
- 안드로이드 앱에서는 휴대폰의 음성 엔진을 써요.
- 한국어 음성이 설치되어 있지 않으면 소리가 안 나거나 어색하게 들릴 수 있어요.

## 사용한 기술

- React, TypeScript, Vite
- Tailwind CSS, shadcn/ui
- Express (개발 서버와 배포 서버 역할만 하고, 앱은 브라우저 안에서 모두 동작해요)
- Capacitor Text-to-Speech
- Pretendard 글꼴

## 폴더 구성

```
client/   화면(React 앱)
server/   개발·배포용 Express 서버
shared/   서버와 화면이 함께 쓰는 코드
```
